# Mohamed & Mariem: Better Together

A 3D co-op love story game in the spirit of *It Takes Two*, made for Mohamed and Mariem, and one day for their children. Twenty chapters follow their real story: two kids at the same school, the physics lesson where it started, the years with no money, Sharm, Cairo, the hard year, America, U3 AI, the Fatiha, the engagement in the garden, Teta Yousr, the best feeling, the yacht, their home, ten exams, Dr. Mariem, the wedding and the family they dream of. Every chapter is built around the two of them working together. Neither of you can finish a chapter alone.

## Play it

**Same computer, right now:** download or clone this repository and open `index.html` in Chrome, Edge or Safari. No install, no build step. Same-screen co-op and solo work straight from the file.

**Online, from two homes:** the game needs to be on a website for online play. It is a static site (no build step), so any static host works:

- **Vercel:** go to [vercel.com/new](https://vercel.com/new), import this GitHub repository, leave every setting on its default (Framework: *Other*, no build command, output = repository root) and press **Deploy**. Every push updates the site.
- **GitHub Pages:** **Settings → Pages → Deploy from a branch**, pick the branch and `/ (root)`.

Online play uses a direct peer-to-peer connection (WebRTC through PeerJS's free servers). One player picks **Play online → Create room**, the other enters the 5-letter code or opens the invite link.

## Modes

| Mode | How it works |
| --- | --- |
| **Play together** | One screen, split down the middle (or a shared camera). Share one keyboard, or use gamepads. |
| **Play online** | Each of you on your own device, each with your own camera. The host picks the chapter. |
| **Play solo** | Control both. `Tab` switches character; `C` calls your partner over when there's a clear path. |

## Controls

| | Player 1 | Player 2 | Gamepad |
| --- | --- | --- | --- |
| Move | `W A S D` | Arrow keys | Left stick / D-pad |
| Jump | `Space` | `Enter`, `.` or Numpad `0` | `A` |
| Power | `E` | Right `Shift`, `/` or Numpad `1` | `X` or `B` |
| Love (hug when close) | `Q` | `,` or Numpad `2` | `Y` |
| Pause | `Esc` / `P` | | `Start` |

With one gamepad connected, it controls Player 2 so Player 1 keeps the keyboard. Phones get an on-screen stick and buttons.

## Two kinds of power

**Mohamed, the big guy:** pushes heavy boxes and furniture, is the only one heavy enough for the gold buttons, **tosses** Mariem up to high ledges (Power next to her) and **ground-slams** through cracked walls (Jump, then Power). Mariem can ride on his shoulders.

**Mariem, the little kitten:** **double jumps**, **dashes** across wide gaps (even in mid-air), runs faster and fits through tunnels he never will.

## Make it even more yours

- **Our album:** every chapter hides memories. Unlock them, then add your own photos in **Our album**. Photos stay on the device (they're never uploaded) and also appear in the 3D photo frames inside the game.
- **Our song:** **Settings → Our song** plays any MP3 instead of the built-in music.
- **Outfits:** chapters dress you for the moment (school uniforms, the white coat, suit and dress, summer clothes, the wedding). Elsewhere, **Settings** picks between *Evening* and *Café date*.
- Progress saves automatically on each device.

## Under the hood

- Plain HTML, CSS and JavaScript with [three.js](https://threejs.org) r160 and [PeerJS](https://peerjs.com) 1.5.4 vendored in `vendor/` (both MIT). No build step.
- All characters, props, music and sound effects are generated in code. There are no image, model or audio files.
- `src/levels.js`, `levels2.js` and `levels3.js` hold the story: themes, memories, the timeline and all 20 chapters. Each level is built from simple pieces (`L.plate`, `L.door`, `L.crate`, `L.elevator`, `L.bridge`, `L.mover`, `L.breakable`, `L.seesaw`, `L.photoSpot`, `L.npc`, `L.waterZone`, `L.paintRoom`, `L.goalZone`...), so it's easy to add a chapter. `src/drive.js` is the driving chapter and `src/concert.js` the rhythm chapter.
- Open the game with `?debug=1` for an FPS readout; press `N` to finish a chapter instantly.
- `tests/` has bot playthroughs that drive both characters through every chapter's puzzles with the real physics, so a layout change that breaks a puzzle shows up as a failure. Run them with `npm install --no-save playwright && npx playwright install chromium && node tests/run.js` (or `node tests/run.js 3 5` for specific chapters). `node tests/smoke.js` loads every chapter and saves a screenshot of each.
